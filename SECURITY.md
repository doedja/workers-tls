# Security

Please report a vulnerability privately, through GitHub's
[private vulnerability reporting](https://github.com/doedja/workers-tls/security/advisories/new),
not in a public issue.

A report is most useful with the version or commit, what an attacker controls
(the server, the proxy, the network between them, or the data the Worker
sends), and what they gain.

Bugs in rustls, rustls-webpki or ring belong upstream. Tell us as well, so the
module can be rebuilt once a fix is out.
